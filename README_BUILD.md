# كيفية تحويل المشروع إلى ملف .exe

لتحويل مشروعك لبرنامج يشتغل على أي جهاز بدون بايثون، اتبع الخطوات دي:

1. افتح موجه الأوامر (CMD) أو الـ Terminal.
2. نزل أداة التحويل بكتابة الأمر ده:
   pip install pyinstaller

3. انسخ الملفات الخارجية بتاعتك (اللي كانت في برنامجك القديم) وحطها جوه مجلد المشروع:
   - `app.ico` (أيقونة البرنامج)
   - `pdftotext.exe`
   - `SumatraPDF.exe`

4. شغل ملف `build.bat` الموجود في المجلد (اضغط عليه دبل كليك).
5. استنى لحد ما يخلص، هتلاقي مجلد جديد اسمه `dist` ظهر.
6. جوه مجلد `dist` هتلاقي مجلد اسمه `main` أو `A2RConsole`، جواه البرنامج بتاعك .exe جاهز للتشغيل!
